# 🌌 太阳系 · Solar System

基于 Three.js (WebGL) 的九大行星太阳系。

## ✨ 功能
- 中心发光太阳（光晕 + 点光源）
- **九大行星**：水星 / 金星 / 地球 / 火星 / 木星 / 土星(光环) / 天王星 / 海王星 / 冥王星
  - 每颗绕日公转（速度随距离递减，符合开普勒趋势）+ 自转
- 地球使用本地高清贴图；其余行星程序化生成纹理（无需外部资源）
- 土星光环、轨道参考线、9000 颗程序化星空
- OrbitControls：拖拽旋转 / 滚轮缩放（带阻尼惯性）

## 🚀 运行
```bash
python3 -m http.server 8901   # 访问 http://localhost:8901
```

纯 Web、无构建步骤，依赖与贴图本地化，离线可运行。
